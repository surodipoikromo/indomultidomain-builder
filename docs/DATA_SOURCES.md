# Data Sources

IndoMultiDomain-Core V1 is constructed from nine openly documented source datasets.

Raw source data are **not mirrored in this repository**. Obtain them from their official repositories and comply with the original licenses.

| SRC003 | IGAR Indonesian Government Application Reviews | Mendeley Data `7zryc6k76z` | Government, health, transport / user reviews |
| SRC004 | BCA Mobile Reviews | Mendeley Data `kgr7x9vs9v/1` | Finance / user reviews |
